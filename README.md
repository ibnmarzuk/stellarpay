# StellarPay

**Payments without borders.**

StellarPay is a payment experience prototype built on the Stellar blockchain. The initial milestone establishes the product direction, architecture, and implementation plan.

## Status

Phase 1: repository foundation and application shell.

## Planned stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Stellar JavaScript SDK
- Freighter wallet integration
- Stellar Testnet

## Development

The application is being implemented in phases. Blockchain interactions will be clearly identified and will only be described as functional after they have been tested against Stellar Testnet.

## Network safety

The MVP targets Stellar Testnet. Testnet assets have no real-world value. Never share or commit wallet secret keys.
